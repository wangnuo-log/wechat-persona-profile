# 好感度多维评分模型（Affinity Model v1）

评估对象固定为**对方对微信机主（用户本人）的好感度**。总分 0-100，五个维度加权合成。
每个维度必须从 `messages.jsonl` 中提取证据（典型原话引用 2-4 条），无证据的维度不得给高分。

## 维度定义与评分规则

### D1 主动性 Initiation（权重 20%）
对方在没有被当前对话牵引的情况下，主动开启交流的倾向。

原料：`stats.json → sessions`
- `other_initiated_ratio = other_initiated / count`（会话段定义：相邻消息间隔 >4h）

| other_initiated_ratio | 得分 |
|---|---|
| ≥0.65 | 90 + 按超出比例加满（95-100） |
| 0.50-0.65 | 75-89 |
| 0.35-0.50 | 55-74 |
| 0.20-0.35 | 35-54 |
| <0.20 | 10-34 |

校正：若 `other_initiated` 的段首消息均为事务性内容（问事、通知、求帮忙），降一档。判据：段首 3 条内无情感/闲聊内容。

### D2 回应度 Responsiveness（权重 20%）
对方对机主消息的响应速度与完整度。

原料：`stats.json → reply_latency.other_to_self`（核心）对照 `self_to_other`（基线）
- 响应率 = 我方消息后被对方接续回复的比例（pairs / self 消息数，近似）
- 平均分桶映射（dist 占比最高的档决定基础分）：

| 主要响应档（占比最高） | 得分 |
|---|---|
| <5min | 90-100（按 pairs 密度微调） |
| 5-30min | 75-89 |
| 30min-2h | 55-74 |
| 2-8h | 35-54 |
| 8-24h | 20-34 |
| >24h 为主 | 5-19 |

加分：对方响应速度显著快于其对我方基线（o2s.avg_min < s2o.avg_min × 0.6）+5。
减分：长回复（>50字）占比极低且多落在敷衍档，-10。

### D3 表达投入 Engagement（权重 15%）
对方在对话中投入的表达量与探索欲。

原料：`stats.json → sides.other`
- 平均字数 avg_chars；提问数 questions；敷衍句 perfunctory 占比

| 组合判据 | 得分 |
|---|---|
| avg_chars ≥40 且 questions/月 ≥5 | 80-100 |
| avg_chars 20-40 且 questions 有稳定出现 | 55-79 |
| avg_chars 10-20，questions 稀少 | 35-54 |
| avg_chars <10 或 perfunctory 占比 >40% | 10-34 |

### D4 情感温度 Affection（权重 25%，核心维度）
语言中的情感倾向：温暖、喜爱、幽默 vs 敷衍、冲突。

原料：`sides.other` 的 pos_words / neg_words / perfunctory + **LLM 必须抽样复核**
- 词典信号：`warmth = pos_words / max(other.text_count,1)`，每百条文本正向词命中数
- 冲突信号：`neg_words` 出现频率、升级轨迹（按月看 neg 是否上升）

| 判据 | 得分 |
|---|---|
| warmth ≥8 且亲昵称呼出现（宝/亲/昵称专属化） | 85-100 |
| warmth 4-8，幽默标记（哈哈/表情包高频）稳定 | 65-84 |
| warmth 1-4，无负面 | 45-64 |
| warmth <1 或 neg 高频 | 15-44 |
| neg 密集且出现断绝/拉黑/激烈冲突词 | 0-14 |

强制规则：本维度必须有 LLM 阅读 ≥50 条对方消息的质性确认，词典计数只决定初档，LLM 可上下调整一档并须说明理由。

### D5 亲密度行为 Intimacy（权重 15%）
超越事务性交流的关系行为。

原料：`sides.other.by_type`、`other_late_night_ratio`、`monthly_counts`
- 表情包/图片互发（sticker+image 占比）；语音消息（voice 视为高信任行为）
- 深夜时段（23:00-05:00）消息占比
- 红包/转账/通话记录
- 分享私人内容：生活照片、情绪倾诉类文本（LLM 判断）

| 命中项数 | 得分 |
|---|---|
| ≥3 项明显 | 80-100 |
| 2 项 | 60-79 |
| 1 项 | 35-59 |
| 0 项 | 10-34 |

## 合成与修正

```
原始分 = 0.20×D1 + 0.20×D2 + 0.15×D3 + 0.25×D4 + 0.15×D5
```

1. **时间衰减**：按月分段计算各维度近期水平，近 3 个月权重 ×1.5，3-12 个月 ×1.0，>12 个月 ×0.7。关系是变化的，过期热情不算数。
2. **样本量置信度**：
   - other 消息 <50 条：不出总分，报告标注"样本不足"；
   - 50-200 条：总分给出但标注"低置信度"；
   - >200 条：正常出分。
3. **关系类型基线**：若会话内容 ≥70% 为事务性（工作/买卖/通知），总分上限压至 59（"友好"封顶），并在报告中说明。

## 等级标定

| 总分 | 等级 | 含义 |
|---|---|---|
| 80-100 | 亲密 | 主动、快速、有温度，存在关系性行为 |
| 60-79 | 亲近 | 稳定投入，情感表达中等 |
| 40-59 | 友好 | 礼貌性互动为主，有基本回应 |
| 20-39 | 平淡 | 低投入、慢响应、事务化 |
| 0-19 | 冷淡 | 敷衍为主或存在负面情绪 |

## 报告呈现要求

- 总分仪表盘 + 五维条形图 + 每维度：分数、权重、等级、**证据引用**（原话，可脱敏）、LLM 一句判词。
- 必须附"方法论与局限"小节：词典局限、样本量、事务性基线、时间衰减说明。不做超出数据支撑的断言。
