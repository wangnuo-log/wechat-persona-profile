# 大五人格聊天推断指南（Big Five from Chat v1）

从 `messages.jsonl` 推断对方的大五人格。每维输出：0-100 分 + 证据原话 2-3 条 + 80 字内描述。
只看对方消息（is_self=false）。分数是相对推断，不是临床诊断，报告须注明。

## O 开放性 Openness
信号：
- 话题多样性：主动引入新话题的领域数（工作/兴趣/时事/情感/抽象讨论）
- 分享链接/文章/音乐/书籍（mtype=link 或文本含 URL）并附自己的观点
- 对新事物的反应词："试试"、"有点意思"、"为什么"、"难道"（好奇标记）
- 想象力表达：比喻、玩笑、脑洞、虚构场景
评分锚点：高频好奇标记 + 观点输出 → 75+；只接受不产出观点 → 40-55；话题单一且回避新话题 → <40。

## C 尽责性 Conscientiousness
信号：
- 承诺-兑现：文本中出现"明天/回头/到时候给你X"后，后续消息是否兑现（LLM 追踪 2-3 个案例）
- 计划性词汇："先…再…"、"排期"、"清单"、"安排"
- 时间敏感：约在具体时间的对话是否守时出现（消息时间戳佐证）
评分锚点：有兑现案例 → 70+；有承诺无兑现 → 40-55；明显随意失约 → <40。

## E 外向性 Extraversion
信号：
- 消息频率与时段广度（白天多时段活跃 = 社交外溢）
- 语音消息占比（voice 视为高外向信号）
- 群聊 vs 私聊活跃度（需要 stats 之外的信息则跳过，不硬判）
- 情感外放：感叹号密度、情绪词直给（"太棒了！！"vs "还行"）
评分锚点：语音多 + 情绪外放 → 75+；文字简短平稳 → 40-55；极少主动且消息极短 → <40。

## A 宜人性 Agreeableness
信号：
- 感谢/赞美频率（谢谢、辛苦、厉害、帮大忙）
- 冲突中的措辞：分歧时是否保留对事不对人的表达（"我可能没说明白"vs"你不懂"）
- 配合度：对请求的回应用"好呀/没问题"vs"哦/行吧"
- 表情包软化：严肃内容是否配表情缓和
评分锚点：感谢高频 + 冲突措辞温和 → 75+；中性礼貌 → 50-65；讽刺/ dismissive 高频 → <40。

## N 神经质 Neuroticism
信号：
- 负面情绪词密度（对照 stats 的 neg_words）
- 焦虑/担忧表达："怕"、" worried"、"睡不着"、"烦死了"
- 深夜情绪化消息占比（23 点后情感倾诉类）
- 感叹号与省略号的情绪性连用（"！！！"、"……"）
评分锚点：情绪词高频 + 深夜倾诉 → 70+；偶有波动 → 40-60；情绪极度平稳 → 20-40。
注意：深夜倾诉也可能只对信任的人展现，判词避免病理化措辞。

## 输出格式（写入报告数据）

```json
{
  "openness":     {"score": 72, "evidence": ["...", "..."], "note": "..."},
  "conscientiousness": {"score": 55, "evidence": ["..."], "note": "..."},
  "extraversion": {"score": 81, "evidence": ["...", "..."], "note": "..."},
  "agreeableness":{"score": 66, "evidence": ["..."], "note": "..."},
  "neuroticism":  {"score": 38, "evidence": ["..."], "note": "..."}
}
```

## 标签系统（配合大五）

从行为特征提炼 3-6 个口语化标签，每个附触发依据：
- 例："表情包狂魔"（sticker 占比 >30%）、"深夜emo型"（23 点后情感消息集中）、
  "已读秒回型"（o2s 主档 <5min）、"话题发动机"（新话题引入高频）、"惜字如金"（avg_chars<8）、
  "语音选手"（voice 占比 >15%）、"报喜不报忧"（pos 高频 neg 近零且从不深夜倾诉）
标签必须有数据触发线，不允许纯印象。
